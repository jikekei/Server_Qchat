# Server_Qcha v2.2.0

## 2.2.0 - 2026-09-30

### Features
- Add per-server game administrator and permission-group management to the Web panel, including offline UserIDs, native permission selection, personal overrides, and reset to group defaults.
- Add plugin permission switches and allow/deny nodes, cross-server group copying, configuration version conflicts, persistence rollback, and audit records. Access requires `game-admin.manage`.
- Add structured permission commands for EXILED and LabAPI while retaining legacy text commands and capability-based upgrade prompts.

### Fixes
- Enforce plugin TCP deadlines by closing timed-out connections, independently of Mono asynchronous cancellation behavior: 2 seconds for incoming requests and 15 seconds for response writes.
- Limit each plugin listener to 32 concurrent connections. Validate frame lengths before allocating bodies, cap incoming frames at 300 KiB, retain 2 MiB responses, and enforce the panel's 256 KiB request limit using UTF-8 bytes.
- Fix overflow in the plugin heartbeat retry counter.

### Interface
- Replace the resource cards with a compact report containing metric, pressure index, and status columns. Keep load summaries, the 60-second peak, advice, and expandable collection details.
- Support mobile layouts and both themes; show placeholders before the first sample.

### Upgrade and validation
- Align Bot, Daemon, Shared runtime, and both plugins to version 2.2.0. Upgrade the Bot and matching plugin together.
- Archives exclude runtime data and local overrides. Replace program files while preserving existing `data/`, `appsettings*.json`, logs, and game configuration. Schedule maintenance before updating the Daemon: its shutdown stops managed game servers.
- LabAPI also requires `dependencies/0Harmony.dll`. Licensed game assemblies are not distributed.
- Bot builds/tests, both plugin builds, and TCP regression tests against both listener implementations are run before publication. Live SCP:SL/Mono integration and restart persistence have not been verified.

### Assets
- `Server_Qcha.Bot-v2.2.0.zip`: Windows framework-dependent Bot/Daemon/Web bundle. Requires the .NET 8 ASP.NET Core Runtime.
- `Server_Qcha-EXILED.dll`: EXILED plugin built with ExMod.Exiled 9.5.0 references.
- `Server_Qcha-LabAPI.dll`: LabAPI plugin; deploy the matching Harmony dependency separately when downloading only the DLL.
- `Server_Qcha-LabAPI-v2.2.0.zip`: LabAPI plugin with `dependencies/0Harmony.dll` included.
- `SHA256SUMS.txt`: checksums for the four downloadable artifacts.

Management covers the standard EXILED permission system and default LabAPI permission provider. Custom providers and plugin-owned permission systems are outside this scope. Undiscovered third-party nodes can be entered manually.
