# QQ 机器人与群服联动指南

作为 Web 管理面板的辅助模块，**Server_Qcha (Qridge)** 提供了与 QQ 群的无缝联动能力，依托 **OneBot 11** 标准协议实现群内查服、玩家数据绑定与游戏内报警推送。

## QQ 框架与协议选择

本项目基于 **OneBot 11 正向 WebSocket** 协议通信，推荐使用目前主流的开源 QQ 框架：
- **[NapCatQQ](https://github.com/NapNeko/NapCatQQ)**（推荐，基于 NTQQ 架构，性能优异且稳定）；
- **[LLOneBot](https://github.com/LLOneBot/LLOneBot)**（基于 LiteLoaderQQNT）；
- **go-cqhttp**（传统协议，部分地区可能存在登录受限）。

---

## NapCatQQ 配置指引

1. 按照 NapCatQQ 官方文档完成登录并打开配置界面；
2. 找到 **网络配置 (Network)** 或 **OneBot 11** 配置项；
3. 开启 **WebSocket 服务端（正向 WS）**：
   - 监听地址：`127.0.0.1`（若同机运行）
   - 端口：`6700`（默认常用端口）
   - Access Token：留空或根据需要设置；
4. 在 `appsettings.Local.json` 中确认机器人连接地址与上述配置一致：
   ```json
   {
     "GoCqHttp": {
       "WsBaseUri": "ws://127.0.0.1:6700"
     }
   }
   ```

## 机器人群白名单与推送设置

在 `appsettings.Local.json` 中：
```json
{
  "Bot": {
    "AllowedGroupIds": [ 123456789 ],        // 允许响应指令的 QQ 群白名单
    "AcTargetGroupId": 123456789             // 接收游戏内 .ac 报警求助的目标 QQ 群号
  }
}
```
- **`AllowedGroupIds`**：填写允许执行机器人指令的 QQ 群号。若数组为空 `[]`，则机器人将响应所有已加入群的指令。
- **`AcTargetGroupId`**：填写接收游戏内玩家 `.ac` 呼叫求助的目标管理群号。

## QQ 群指令大全

### 普通玩家指令
群内所有成员均可直接发送以下指令进行查询：

| 指令 | 说明 | 示例 | 回显说明 |
|---|---|---|---|
| `help` | 显示机器人指令帮助菜单 | `help` | 返回基础指令速查文本 |
| `cx` | 汇总查询所有服务器在线人数与状态 | `cx` | 显示各服名称、在线人数/上限及延迟 |
| `info` | 查询服务器配置详情 | `info` | 显示服务器基础信息与描述 |
| `#1` | 查看 1 号服当前在线玩家详情 | `#1` | 列出该服全部玩家昵称、角色、SteamID 与延迟 |
| `#2` | 查看 2 号服当前在线玩家详情 | `#2` | 同上 |
| `/bd <Steam64>` | 将本人的 QQ 号与 Steam64 ID 绑定 | `/bd 76561198000000000` | 绑定成功后记录入数据库 |
| `/me` | 查询自己绑定的 Steam 游戏游玩统计 | `/me` | 返回游玩时长、胜率及战绩统计 |

---

### 群管理指令
仅限群主或群管理员使用（具有权限校验保护）：

| 指令 | 说明 | 示例 | 行为说明 |
|---|---|---|---|
| `/bc <服号> <内容>` | 向指定服务器发送全局广播 | `/bc 1 服务器将在5分钟后维护` | 游戏内全体玩家屏幕显示广播通知 |
| `/round <服号>` | 强制重启指定服务器当前回合 | `/round 1` | 向游戏服下发 `rest` 回合重置指令 |
| `/ban <服号> <ID> <时长> <原因>` | 踢出或封禁指定玩家 | `/ban 1 2 60m 违规使用外挂` | 向游戏服下发踢出/封禁指令 |
| `/setadmin <服号> <ID> <组名>` | 临时分配游戏内权限组 | `/setadmin 1 2 admin` | 为对局内指定玩家临时授予管理组 |

## 玩家数据互通与绑定

若您的服务器配置了 MySQL 数据库存储玩家数据：
1. 玩家在 QQ 群内输入 `/bd 76561198xxxxxxxx`；
2. 机器人将发送者的 QQ 号与输入的 Steam64 写入数据库绑定表；
3. 玩家后续在群内输入 `/me` 时，系统将自动读取其关联的 Steam 战绩并格式化展示；
4. 服主也可在 Web 面板的数据库管理模块中统一检索和维护绑定记录。
