v2.4.2 为运维 API 增加 QQ 机器人指令接口，并在 Web 面板提供多令牌管理。

## 从 v2.4.1 升级时需要更新哪些组件

| 组件 | 是否需要更新 | 说明 |
| --- | --- | --- |
| Bot 和 Web 面板 | **需要** | 新增 QQ 指令 API 和多令牌管理。 |
| 守护进程 | 无需更新 | 可以保持运行，托管游戏服继续服务。 |
| LabAPI 插件 | 无需更新 | 继续使用 v2.4.0。 |
| EXILED 插件 | 无需更新 | 继续使用 v2.4.0。 |

## 本次更新

- **QQ 机器人指令 API**：调用 `POST /api/ops/v1/bot/commands` 可执行 QQ 指令和别名，并在 HTTP 响应中读取完整回复。管理指令会实际执行，调用需要启用运维控制。
- **多令牌管理**：在「API 与日志归档」中为不同调用方创建命名令牌，按需单独撤销。旧版令牌继续有效，并以「原有令牌」显示。

## 从 v2.4.1 升级

1. 备份 `data/` 和现有 `appsettings*.json`。
2. 停止 Bot，从对应平台的压缩包替换根目录的 `Server_Qcha.Bot`（Windows 为 `Server_Qcha.Bot.exe`）、`runtime/Server_Qcha.Bot.*` 和 `wwwroot/`。
3. 启动 Bot 并刷新面板。
