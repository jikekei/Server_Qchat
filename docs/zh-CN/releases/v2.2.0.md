# Server_Qcha v2.2.0

## 2.2.0 - 2026-09-30

### 新功能
- Web 面板新增游戏管理员管理：按服务器读取和管理管理员、权限组及预设，支持离线 UserID、逐项原生权限、个人覆盖和恢复跟随权限组。
- 插件权限支持总开关与允许 / 拒绝节点；支持权限组跨服复制、配置版本冲突检测、持久化回滚及审计记录。新模块需要 `game-admin.manage` 权限。
- EXILED 与 LabAPI 插件增加结构化权限命令；旧文本命令保留兼容，旧插件通过能力查询提示升级。

### 修复
- 插件 TCP 请求使用独立超时并关闭连接，不再依赖 Mono 对异步读取取消令牌的支持；读取限时 2 秒，响应写入限时 15 秒。
- 每个插件监听器最多接纳 32 个并发连接；入站帧限制 300 KiB，长度校验后才分配正文内存。响应上限保留 2 MiB，面板请求按 UTF-8 字节限制 256 KiB。
- 修复插件心跳失败重试计数溢出。

### 界面
- 主页资源模块改为紧凑三列表格，只显示指标、压力指数与状态；保留综合负载、平滑值、60 秒峰值、运行建议和采集明细。
- 适配手机与深浅色主题；未采集的数据显示占位，避免误报零负载。

### 升级与验证
- Bot、守护进程、共享运行时及两套插件版本统一为 2.2.0；建议同步升级 Bot 和对应游戏服插件。
- 发布包不包含运行数据或本机配置。升级只替换程序文件，保留现有 `data/`、`appsettings*.json`、日志及游戏服配置。更新守护进程前安排维护窗口，其退出会停止托管游戏服。
- LabAPI 必须同时部署 `dependencies/0Harmony.dll`；不包含游戏程序集。
- Bot 构建和自动化测试、两套插件编译及针对两套监听器的 TCP 回归测试在发布前执行；真实 SCP:SL / Mono 联调与游戏服重启持久化验证尚未完成。

### 下载文件
- `Server_Qcha.Bot-v2.2.0.zip`：Windows 框架依赖部署包，包含 Bot、Daemon、Web 面板、默认配置和启动脚本；需要 .NET 8 ASP.NET Core Runtime。
- `Server_Qcha-EXILED.dll`：EXILED 插件（按 ExMod.Exiled 9.5.0 引用编译）。
- `Server_Qcha-LabAPI.dll`：LabAPI 插件；仅下载 DLL 时须另行部署配套 Harmony 依赖。
- `Server_Qcha-LabAPI-v2.2.0.zip`：包含 `Server_Qcha.dll` 和 `dependencies/0Harmony.dll` 的 LabAPI 完整插件包。
- `SHA256SUMS.txt`：上述四个下载产物的 SHA-256 校验值。

支持范围：EXILED 标准权限系统及 LabAPI 默认权限提供器。自定义提供器或插件自建权限系统不在管理范围内；第三方节点可手动录入，不保证自动发现全部节点。
