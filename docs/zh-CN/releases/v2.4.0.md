## 玩家统计与数据库封禁

- LabAPI 和 EXILED 插件可接入运维面板使用的 MySQL 库。玩家时长、击杀和阵亡按增量写入现有 `PlayerData`，保留 QQ 绑定和管理员资料。
- 插件在新玩家加入时及游戏过程中检查 `BanPlayerData`，按完整账号 ID 执行有效封禁。面板解除数据库封禁后，玩家可重新加入。游戏原生封禁由游戏原生功能管理。
- 面板使用数据库时间保存和判断封禁期限。玩家统计和 QQ 绑定统一使用 `PlayerData` 表名。

## 下载与配置

- 面板和守护进程使用对应平台的 `Server_Qcha.Bot-v2.4.0-win-x64.zip` 或 `Server_Qcha.Bot-v2.4.0-linux-x64.zip`。
- 游戏服按框架下载 `Server_Qcha-LabAPI-v2.4.0.zip` 或 `Server_Qcha-EXILED-v2.4.0.zip`，同时部署包内的 `Server_Qcha.dll` 和 `dependencies/`。
- 在插件配置中设置 `database_connection_string`，指向面板使用的同一个数据库。若同台服仍由其他插件写入这份统计，可将 `database_player_stats_enabled` 设为 `false`，继续使用数据库封禁。
- 升级时保留原有配置和 `data/`。在维护窗口切换守护进程，其退出会停止托管的游戏服。

## 验证范围

Windows 和 Linux 主程序包通过解压启动验证。两版插件均通过编译。临时 MariaDB 验证了并发累加、QQ 绑定、旧表兼容和封禁查询。真实客户端的踢出和重连还需在游戏服验证。
