v2.4.3 在 Web 面板加入 MySQL 备份，并让 QQ 机器人的服务器汇总自动隐藏空服。

> [!NOTE]
> **从 v2.4.2 升级时，只需更新 Bot 和 Web 面板。** 守护进程、LabAPI 和 EXILED 插件均无需更新，游戏服可以继续运行。

## 本次更新

- **MySQL 备份**：在「数据库管理 → MySQL 备份」查看备份记录或手动触发。自动备份每天在 Bot 主机时间 03:00 执行，保留最近 5 份日备份、5 份月备份，年备份永久保留。
- **自动配置备份工具**：Windows 和 Linux x64 上缺少兼容的 `mysqldump` 时，Bot 会在首次备份时从 MySQL 官方下载客户端并保存到 `data/tools/`。Linux 自动安装需要 `tar` 和 `xz`。
- **QQ 服务器汇总**：`/cx` 和 `/info` 自动隐藏确认无人的服务器。所有服务器正常响应且无人在线时，回复「全服运行正常，当前暂无玩家在线，别等了，赶紧上线暖服！」。状态查询失败时会另行提示。

## 从 v2.4.2 升级

停止 Bot 后，从对应平台的压缩包替换根目录的 `Server_Qcha.Bot`（Windows 为 `Server_Qcha.Bot.exe`）、`runtime/Server_Qcha.Bot.*` 和 `wwwroot/`。保留 `data/` 及现有 `appsettings*.json`，启动 Bot 后刷新面板。

MySQL 备份覆盖表结构、数据、视图和触发器。存储过程、函数和事件需要另行导出。备份保留和失败处理已通过自动化测试，真实 MySQL 导出和还原尚未联调。
