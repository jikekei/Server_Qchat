v2.4.1 修复守护进程读取本机配置的问题，并更新 Windows 启动提示，方便确认 Web 面板实际监听的地址和端口。

## 修复

- **守护进程读取本机配置**：现在会加载程序目录中的 `appsettings.Local.json`。本机配置可覆盖 `appsettings.Production.json` 中的同名设置，环境变量和命令行参数仍可覆盖配置文件。通过面板保存的实例继续以 `data/localadmin-servers.json` 为准。
- **面板监听提示**：Windows 一键启动脚本和 Bot 重复启动提示会引导你查看 Bot 的 `Now listening on` 日志。需要排查监听地址时，可以同时检查 `WebPanel.Host` 和环境变量 `WebPanel__Host`。

## 下载与升级

- [Windows x64 自包含包](https://github.com/jikekei/Server_Qchat/releases/download/v2.4.1/Server_Qcha.Bot-v2.4.1-win-x64.zip)
- [Linux x64 自包含包](https://github.com/jikekei/Server_Qchat/releases/download/v2.4.1/Server_Qcha.Bot-v2.4.1-linux-x64.zip)

请在维护窗口停止 Bot 和守护进程，备份 `data/` 和现有 `appsettings*.json`，再替换 Bot、守护进程及 `runtime/`。守护进程退出时会停止它托管的游戏服。已有 Windows 启动脚本可一起替换。

已使用 v2.4.0 LabAPI 或 EXILED 插件的游戏服可继续使用该版本。首次安装插件可从 [v2.4.0 发布页](https://github.com/jikekei/Server_Qchat/releases/tag/v2.4.0) 下载。
