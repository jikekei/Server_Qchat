## 主要更新

- **SteamCMD 更新与回滚**。可在 Web 面板暂存下载游戏服更新，等回合结束或空服再切换。新版本启动失败时自动回滚，也可以从面板手动回滚。
- **实时控制台**。新日志到达即显示。向上翻阅时保留阅读位置，点击「跟随最新」跳到底部。连续按回车只提交一次正在发送的指令。
- **按服自动回收内存**。默认阈值为 2 GiB。持续超限后，空服会优雅重启，有玩家时通过游戏原生 `rnr` 安排回合结束后的重启和重连。各实例可以调整阈值，设为 `0` 可关闭。
- **运维 API 与归档日志**。提供独立的运维 API 凭据、服务器进程操作和历史日志读取。

## 下载与升级

- Windows x64 使用 `Server_Qcha.Bot-v2.3.0-win-x64.zip`。
- Linux x64 使用 `Server_Qcha.Bot-v2.3.0-linux-x64.zip`。
- 两个包都包含 Bot、守护进程、Web 面板和 .NET 运行时。可执行文件位于根目录，DLL 集中在 `runtime/`。
- 升级时解压到新目录，迁移原有配置、`data/` 和所需日志，再在维护窗口切换 Bot 和守护进程。停止守护进程会停止它托管的游戏服。
- 游戏服插件可继续从 [v2.2.0 下载](https://github.com/jikekei/Server_Qchat/releases/tag/v2.2.0)。
