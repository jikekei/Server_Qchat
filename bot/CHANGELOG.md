# Changelog

## 2.2.0 - 2026-09-30

### 新功能
- Web 面板新增游戏管理员管理：按服务器读取和管理管理员、权限组及预设，支持离线 UserID、逐项原生权限、个人覆盖和恢复跟随权限组。
- 插件权限支持总开关与允许 / 拒绝节点；支持权限组跨服复制、配置版本冲突检测、持久化回滚及审计记录。新模块需要 `game-admin.manage` 权限。
- EXILED 与 LabAPI 插件增加结构化权限命令；旧文本命令保留兼容，旧插件通过能力查询提示升级。

### 修复
- 插件 TCP 请求使用独立超时并关闭连接，不再依赖 Mono 对异步读取取消令牌的支持；读取限时 2 秒，响应写入限时 15 秒。
- 每个插件监听器最多接纳 32 个并发连接；入站帧限制 300 KiB，长度校验后才分配正文内存。响应上限保留 2 MiB，面板请求按 UTF-8 字节限制 256 KiB。
- 修复插件心跳失败重试计数溢出。

### 界面
- 主页资源模块改为紧凑三列表格，只显示指标、压力指数与状态；保留综合负载、平滑值、60 秒峰值、运行建议和采集明细。
- 适配手机与深浅色主题；未采集的数据显示占位，避免误报零负载。

### 升级与验证
- Bot、守护进程、共享运行时及两套插件版本统一为 2.2.0；建议同步升级 Bot 和对应游戏服插件。
- 发布包不包含运行数据或本机配置。升级只替换程序文件，保留现有 `data/`、`appsettings*.json`、日志及游戏服配置。更新守护进程前安排维护窗口，其退出会停止托管游戏服。
- LabAPI 必须同时部署 `dependencies/0Harmony.dll`；不包含游戏程序集。
- Bot 构建和自动化测试、两套插件编译及针对两套监听器的 TCP 回归测试在发布前执行；真实 SCP:SL / Mono 联调与游戏服重启持久化验证尚未完成。


## v2.0.0 — 2026-09-21

### 新特性与架构升级
- **独立常驻守护进程架构 (Server_Qcha.Daemon)**：
  - 将 SCPSL 服务端托管彻底解耦至独立常驻进程，升级或重启 Bot 时游戏服和在线玩家永不掉线。
  - Web 面板增加守护进程核心性能实时监控看板（工作集内存、专用内存、运行时长、线程数）与生命周期控制（启动、关机、重启）。
- **QQ 官方 Bot API 原生集成**：
  - 完整实现 QQ 开放平台 OpenAPI v2（基于 WebSocket 长连接、AccessToken 动态刷新与心跳保活机制）。
  - 支持群聊与单聊消息收发、被动回复配额管理（`msg_seq`）与长文本自动智能分段。
- **NapCat / QQ 官方 双接入热切换**：
  - 支持在 NapCat (OneBot 11) 与 QQ 官方 Bot API 之间在线切换，自动平滑迁移连接，无需重启进程。
- **QQ 官方指令面板（/v2/panels）自动创建与管理**：
  - 自动将 `BotCommandCatalog` 中的 11 条指令转换为腾讯官方规格（名称 <= 14 字符、介绍 <= 30 字符）。
  - 群聊场景自动为管理员命令（`/bc`、`/round`、`/ban`、`/setadmin`）打上 `only_admin: true` 权限标识。
  - Web 面板提供一键同步、实时拉取查看与面板删除功能。
- **现代化 Web 控制台（Qridge）**：
  - 基于 Vue 3 + Element Plus 的单页控制台，提供仪表盘、服务器管理、数据库查询、账户管理与审计日志。
  - 内置基于 SQLite 的轻量本地数据库（`panel.db`），支持 RBAC 权限体系与完整操作审计。
- **持久化数据集中隔离**：
  - 引入 `DataDirectoryManager`，所有本地运行时状态文件统一收敛至 `data/` 目录（`panel.db*`、`bot-settings.json`、`localadmin-servers.json`、`logging-level.json`），环境隔离与备份迁移更方便。
- **玩家历史趋势采样与统计**：
  - 全自动周期性采样玩家在线数，支持当日峰值统计与可视化折线图。
